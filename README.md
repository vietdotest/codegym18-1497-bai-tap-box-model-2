# Open Source Records

Hoàn thiện CSS của nội dung mẫu Open Source Records: thanh liên kết, Bio, Members, Albums, Tour Dates. Giữ các màu chữ theo đề; bổ sung margin, padding, border và width. Các trang phụ giúp liên kết About, Bands, Contact hoạt động.

## Chạy
Mở index.html trong trình duyệt.

## Đề bài
https://internship.codegym.vn/learning/18/activity/1497

## Kiểm tra
Đã mở ở 375, 768, 1440 px và kiểm tra box-sizing, padding, border, margin trong trình duyệt. Ảnh result.png là kết quả chạy nếu bài yêu cầu nộp ảnh. Kích thước CSS có thể được làm tròn nhẹ theo mức zoom trình duyệt.
